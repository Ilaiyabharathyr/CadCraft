---
title: Change the interface language
description: Switch the CADCraft menus and dialogs to another language, or follow your system language.
order: 50
verified: 0.5.0
---

Choose **Edit ▸ Interface Language** and pick a language from the list. The interface changes without a restart.

## Steps

1. Choose **Edit ▸ Interface Language**. A small window opens.
2. Open the drop-down list in it.
3. Pick one of these:
   - **Auto (system language)**
   - **English**
   - **Українська**
   - **Português (Brasil)**
   - **Deutsch**
   - **Español**
   - **Čeština**
   - **Русский**
   - **Français**

CADCraft remembers your choice. With **Auto (system language)**, it follows your operating system's language. If your system language is not one of the supported ones, the interface is in English.
